# 🎙️ AnaZone | المساعد الصوتي ومستكشف العالم الذكي

منصة **AnaZone** المتكاملة (Full-stack Clean Code) تدمج أحدث تقنيات ونماذج الذكاء الاصطناعي الصوتي والمحادثات باللغة العربية واستكشاف العالم التفاعلي.

---

## 🏗️ البنية المعمارية للمشروع (Architecture)

1. **التعرف على الكلام (STT - Speech to Text):**
   - **Cloudflare Workers AI**: نموذج `whisper-large-v3-turbo`.
   - يتعرف تلقائياً على العربية والإنجليزية.

2. **عقل المحادثة والاستدلال (LLM Inference):**
   - النموذج: `claude-sonnet-9`.
   - نقطة النهاية (Endpoint): تضبط عبر متغير البيئة `LLM_API_URL` في ملف `.env` (الافتراضي: `http://127.0.0.1:4000/v1/chat/completions`).
   - يجيب بلغة رسالة المستخدم الأخيرة مع الحفاظ على الشخصية المختارة.

3. **تحويل النص إلى كلام (TTS - Text to Speech):**
   - محرك **`VoiceTut-TTS`** الصوتي.
   - يستخدم الصوت المختار نفسه عند النطق بالعربية والإنجليزية، مع ضبط لغة التوليد على لغة الرد.
   - 3 شخصيات صوتية منتقاة:
     - **ياسمين (`spk_18_female`)**: بيئة عمل وتنسيق احترافي وهادئ.
     - **أحمد (`spk_01_male`)**: خدمة عملاء ودعم فني وودي.
     - **طارق (`spk_10_male`)**: إعلانات وترويج حماسي وقوي.
   - لا يستخدم Edge TTS.

4. **الواجهة الأمامية (Frontend):**
   - **Next.js (App Router)** مع **Tailwind CSS**.
   - خط **DM Sans**.
   - لوحة الألوان المعتمدة (4 ألوان فقط): `#0b6623` و `#2e8b57` و `#78866B` واللون الأبيض `#ffffff` للنصوص.
   - استخدام صورة الباندا الأصلية `confirmed_bg.jpeg` في القسم العلوي (Hero Section)، مع وضع العنوان والوصف وسهم الانتقال على يسار الباندا.
   - قسم الوكيل الصوتي بخلفية بيضاء، ومحادثة مستمرة دون استخدام خلفيات سوداء.

5. **الواجهة الخلفية (Backend):**
   - **FastAPI** سريع وخفيف ومنظم بنمط الخدمات والمسارات المستقلة (`services/` و `routers/`).

---

## 🚀 طريقة التشغيل (How to Run)

### 1. تشغيل الباك إند (Backend):
```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
- واجهة التوثيق التفاعلية (Swagger API): [http://localhost:8000/docs](http://localhost:8000/docs)

### 2. تشغيل الفرونت إند (Frontend):
```powershell
cd frontend
npm run dev
```
- رابط المنصة: [http://localhost:3000](http://localhost:3000)
