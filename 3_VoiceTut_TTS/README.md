# 🇪🇬 VoiceTut-TTS (اللهجة المصرية الأصلية)

نموذج مفتوح المصدر متخصص بالكامل في **اللهجة المصرية العامية** بدون أي لكنة أجنبية، مدرب على أكثر من **380 ساعة** من البودكاستات المصرية الحقيقية.

- **المطور:** Mohammed Aly (`MohammedAly22`)
- **المعمارية:** OmniVoice Backbone + Egyptian Speech Adapter
- **المستودع على GitHub:** [MohammedAly22/VoiceTuT-TTS](https://github.com/MohammedAly22/VoiceTuT-TTS)
- **Hugging Face Model:** [mohammedaly22/VoiceTut-TTS](https://huggingface.co/mohammedaly22/VoiceTut-TTS)

---
